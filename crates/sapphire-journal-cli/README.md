# sapphire-journal-cli

The command line of [sapphire-journal](https://github.com/sapphire-turtle/sapphire-journal)'s
two editions: its commands (`entry`, `cache`, `config`, and sapphire-framework's `serve`,
`status`, `service`, `workspace`, `mcp`, …), the app server and the MCP server, as a library.

To install the command, see [`sapphire-journal-headless`](../../headless/README.md) (no GUI)
or the desktop app; both put `sapphire-journal` on PATH.
